# 返却確認を貸出集約の状態遷移にする

返却確認は別の集約にせず、貸出集約の不可逆な状態遷移として表す。貸出は実際の返却日時と返却を確認した管理者を最大1組保持し、返却済みから貸出中へ戻せないようにする。別の返却確認レコードでは1件の貸出に対する返却確認の一意性が集約の外へ漏れ、機材集約へ置くと貸出履歴を抱え込むためである。

返却対象は機材の管理番号から未返却貸出を探すが、確定時には見つけた貸出の識別子である予約IDも照合する。これにより窓口では物理的な機材から操作を始めつつ、古い返却要求の再送によって同じ機材の新しい貸出を誤って返却済みにすることを防ぐ。

返却確認できるのは管理者だけとし、貸出集約は返却を確認した利用者IDと、呼び出し元で確認済みの管理者性を状態遷移時に受け取って検査する。管理者性は貸出へ保存せず、認証や役割の照会も行わない。これは予約取消と同じ構成であり、認証と従業員マスタを初期対象外とした [ADR-0001](./0001-single-site-individual-equipment.md) の範囲を維持する。

同じ管理番号に対する返却確認と新しい予約または貸出は、原子的な確定順に従って判定する。返却が先に確定すれば後続操作は返却済みとして判定でき、後続操作が先なら未返却として失敗する。返却確認に特別な優先権や自動再試行は設けない。

返却確認の最終確定は、汎用リポジトリや貸出作成用のポートを使わず、専用の `LoanReturnConfirmer` ポートで原子的に行う。管理番号に対する現在の未返却貸出が、返却済みへ遷移させた貸出の予約IDと一致することを再検査して保存し、成功、返却済み、現在貸出中でない、表示時から別の貸出へ変わった、を区別して返す。ロックやトランザクションなどの実現方法は永続化設計時に決める。
