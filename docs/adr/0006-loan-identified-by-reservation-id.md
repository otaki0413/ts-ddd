# 貸出を予約IDで識別する独立した集約にする

貸出を予約とは別の集約とし、識別子には貸出IDを新設せず予約IDを使う。1件の予約から生じる貸出は最大1件([ADR-0003](./0003-separate-reservation-and-loan.md))という不変条件が予約IDの一意性と一致するため、貸出IDを導入すると同じ制約を二重に管理することになる。代理受取や予約に基づかない貸出を扱う段階になったら識別子を再検討する。

貸出可否は、予約、機材、その機材の未返却貸出、現在日時を受け取る I/O を行わないドメインポリシーが判断する([ADR-0004](./0004-separate-equipment-and-reservation-aggregates.md) と同じ構成)。最終確定は原子的に行い、直前の予約取消、同じ予約への二重貸出、直前の利用停止、未返却貸出の発覚は確定側で防ぐ。アプリケーション層ではこの契約を `LoanCommitter` ポートとして表し、成功、取消済み、貸出済み、利用停止、機材未返却を区別して返す。予約失効(返却予定日時の経過)はポリシーが受け取った現在日時での判定を最終とし、確定側では再検査しない。ロックやトランザクションなどの実現方法は永続化設計時に決める。
