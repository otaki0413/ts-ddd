# 単一拠点の個体管理にスコープを限る

このリポジトリは TypeScript と DDD の学習用で、1つの工場・事業所で共用する測定器や電動工具を、管理番号で1台ずつ識別して予約・貸出する。同種品の数量管理、消耗品、複数拠点、予約の承認フロー、認証、従業員マスタ、機材種別の管理機能、代理受取、予約なしの直接貸出、通知、延滞への罰則、修理・廃棄の詳細管理、Web画面は初期対象外。初期版のユースケースは呼び出し元で事前登録済みと確認された外部の利用者IDを受け取り、認証や従業員マスタへの問い合わせは行わない。予約可能なら承認を挟まず予約が成立する。ドメイン層とアプリケーション層を外部技術から独立させる。
