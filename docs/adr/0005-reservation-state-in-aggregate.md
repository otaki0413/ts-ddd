# 予約の状態遷移を予約集約の中で強制する

予約中と取消済みを予約集約が持つ状態として表し、予約取消は集約の遷移操作として実装する。取消済みへ至った予約を予約中へ戻せないという制約と、取り消せるのは予約者本人または管理者だけという業務ルールは、この遷移操作がドメインルールとして検査する。取消を別レコードとして保存しクエリ側で除外する案は、予約の不変条件の置き場所が集約の外へ分散するため採らない。

貸出済みは貸出の存在から、予約失効は現在日時と返却予定日時から導出し、格納する状態にはしない。これは [ADR-0004](./0004-separate-equipment-and-reservation-aggregates.md) で予約失効を格納せずドメインポリシーが判定するとした方針を予約取消にも揃えるものである。

取消の最終確定は予約成立と同様に原子的に行い、直前に貸出が生じた予約は取り消さない。アプリケーション層ではこの契約を `ReservationCanceller` ポートとして表し、成功、貸出済み、取消済み、予約失効を区別して返す。ロックやトランザクションなどの実現方法は永続化設計時に決める。
