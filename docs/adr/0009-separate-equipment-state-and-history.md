# 機材の現在状態と全履歴を分けて保持する

機材集約は現在の利用可否、版番号、直前の利用停止・利用再開日時を保持し、件数が増え続ける全履歴は集約の外へ追記保存する。状態・版番号・履歴追加は一度に原子的に確定し、照会では同じ確定時点の状態・版番号とその版までの履歴を一組で取得するポート契約とする。同じ管理番号への予約・貸出との競合は、[ADR-0004](./0004-separate-equipment-and-reservation-aggregates.md) と [ADR-0006](./0006-loan-identified-by-reservation-id.md) の専用確定ポートを含む原子的な確定順に従い、各ポートが確定時の利用可否を再検査する。具体的なDB、ロック、トランザクションの方式は永続化設計時に決める。
