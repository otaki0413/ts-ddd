# 機材予約・貸出管理アプリの概要

## 目的

単一の工場・事業所で共用する機材について、誰がいつ利用する予定か、現在誰へ貸し出しているかを把握できるようにする。

利用者は指定した期間に予約可能な機材を事前に予約でき、管理者は予約に基づく貸出と返却確認を記録できる。これにより、機材の重複利用や所在不明を防ぐ。

この文書の内容は、実装を通して業務理解が深まった場合に見直す。

## 対象者

- **利用者**: 機材を予約し、借り受ける従業員
- **管理者**: 機材を登録し、貸出、返却確認、利用停止を記録する担当者

従業員の情報は共通化し、管理業務を行える従業員に管理者の役割を付与する。同じ従業員が両方の役割を持てる。

初期段階では認証・認可や従業員情報の管理機能を実装せず、事前登録された従業員のIDを使用する。管理操作には、操作した管理者のIDを記録する。

## 対象とする機材

測定器や電動工具など、管理番号によって1台ずつ識別できる機材を扱う。機材には、変更できない管理番号のほか、名称、事前に定義された機材種別、保管場所を登録する。名称、機材種別、保管場所は管理者が変更できる。

保管場所は「工具室A」などの文字列とし、場所自体はマスタ管理しない。貸出中の所在は現在の借用者から判断し、本来の保管場所は返却先として保持する。

同種の機材を数量だけで管理する在庫・消耗品管理は対象にしない。

## 基本業務フロー

1. 管理者が機材を登録する。
2. 利用者が予約期間を指定し、その期間に予約可能な機材を確認する。
3. 利用者が機材を1台選んで予約し、予約可能なら承認を挟まず確定する。
4. 管理者が予約者本人へ機材を引き渡し、実際の貸出日時を記録する。
5. 管理者が返却された機材を受け取り、実際の返却日時を記録して返却を確認する。
6. 故障や点検が必要な場合、管理者が機材を利用停止にする。問題が解消したら利用を再開する。

## 初期ユースケース

- 機材を登録する
- 機材情報を変更する
- 指定期間に予約可能な機材を確認する
- 機材を予約する
- 予約者が予約を取り消す
- 管理者が理由を付けて予約を取り消す
- 予約済みの機材を貸し出す
- 貸出中の機材の返却を確認する
- 機材を利用停止にする
- 機材の利用を再開する

## 業務ルール

### 機材

- 機材の管理番号は重複せず、登録後に変更できない。
- 機材は物理削除しない。使用しなくなった機材は、初期版では利用停止として扱う。

### 予約

- 新しい予約の利用開始予定日時は、予約操作時点以降でなければならない。
- 利用開始予定日時は返却予定日時より前でなければならない。
- 予約期間は利用開始予定日時を含み、返却予定日時を含まない。前の予約の返却予定日時と次の予約の利用開始予定日時が同じ場合は重複しない。
- 同じ機材に対して、予約期間が重なる予約を確定できない。取り消された予約、失効した予約、貸出後に返却確認が完了した予約は重複判定の対象にしない。
- 利用停止中の機材を新たに予約できない。
- 1件の予約で扱う機材は1台とする。
- 確定した予約の機材や予約期間は変更できない。変更する場合は取り消して予約し直す。
- 予約者は、貸出前なら期限なく予約を取り消せる。管理者は、貸出前の予約を理由付きで取り消せる。
- 貸出されないまま返却予定日時を過ぎた予約は、日時から予約失効と判定する。
- 予約期間の長さや、予約可能になる日について初期版では制限を設けない。

### 貸出と返却

- 確定した予約がなければ機材を貸し出せない。
- 機材は予約者本人にだけ貸し出せる。代理受取や予約なしの直接貸出は扱わない。
- 機材を貸し出せるのは、利用開始予定日時以降、返却予定日時より前に限る。
- 1台の機材を同時に複数の利用者へ貸し出せない。
- 貸出中でない機材の返却を確認できない。
- 返却予定日時を過ぎても貸出中なら、日時から延滞と判定する。通知、罰則、利用制限は行わない。
- 延滞中の機材は次の予約者へ貸し出せない。次の予約期間内に返却されれば、その時点から次の予約者へ貸し出せる。
- 予定より早く返却された場合、元の返却予定日時は履歴として保持し、実際の返却日時以降を新しい予約に利用できる。

### 機材の利用停止

- 管理者は、将来の予約や現在の貸出があっても機材を利用停止にできる。
- 貸出中に利用停止にした場合、実物が管理者へ戻るまで貸出中のままとし、返却を確認した後も利用停止を維持する。
- 利用停止中は、新しい予約と貸出を禁止する。影響を受ける貸出前の予約は、管理者が理由付きで取り消す。
- 返却時に故障が判明した場合は、返却を完了すると同時に機材を利用停止にする。
- 利用を再開できるのは、機材が貸出中でない場合に限る。

用語の定義は[ユビキタス言語](ubiquitous-language.md)にまとめる。

## 初期対象外

- 複数拠点と拠点間の機材移動
- 同種品の数量管理と消耗品の在庫管理
- 予約の承認フロー
- ログイン、認証、権限管理
- 従業員情報と機材種別の管理機能
- 代理受取、予約なしの直接貸出、過去の貸出実績の登録
- メールなどによる通知
- 延滞への罰則や利用制限
- 修理、点検作業の詳細な管理
- 機材の廃棄・除却
- Web画面

Web画面は、Hono APIの完成後に追加を検討する。

## 将来検討すること

- 名称、管理番号、機材種別、状態などによる検索・絞り込み
- 予約期間や予約可能日についての制限
- 予約者以外による代理受取
- 利用停止中の返却依頼や回収状況の管理
- 修理、点検、廃棄・除却の管理

業務上の日時は日本時間（`Asia/Tokyo`）として入力・表示する。データベースへの保存形式は永続化方式を決める際に検討する。
