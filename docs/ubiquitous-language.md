# ユビキタス言語

機材予約・貸出管理の会話、ドキュメント、コード、テストで使用する言葉を定義する。業務理解が変わった場合は、実装とともにこの文書も見直す。

## 人と役割

| 用語   | 意味                                                       |
| ------ | ---------------------------------------------------------- |
| 利用者 | 機材を予約し、借り受けられる事前登録済みの従業員           |
| 予約者 | 予約を作成し、その予約に基づいて機材を借り受ける利用者     |
| 借用者 | 貸出中の機材を実際に借りている利用者                       |
| 管理者 | 機材、貸出、返却確認、利用停止に関する管理操作を行う利用者 |

同じ従業員が利用者と管理者の両方の役割を持てる。初期版では予約者本人だけに貸し出すため、予約者と借用者は同一人物になる。

## 機材

| 用語       | 意味                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 機材       | 管理番号によって1台ずつ識別する貸出対象                                |
| 管理番号   | 事業所内で機材を一意に識別する、登録後に変更できない番号               |
| 機材種別   | 測定器や電動工具など、機材を分類する事前定義済みの区分                 |
| 保管場所   | 貸出されていない機材を通常保管し、返却する場所                         |
| 所在       | 機材が現在ある場所。貸出中なら借用者、それ以外なら保管場所から判断する |
| 利用可能   | 機材が利用停止中ではないこと                                           |
| 利用停止中 | 故障や点検のため、新しい予約と貸出を禁止している状態                   |
| 予約可能   | 指定した予約期間に重複する予約がなく、機材が利用可能であること         |

管理者が機材を利用停止にする。問題解消後、機材が貸出中でなければ利用を再開する。

## 予約

| 用語             | 意味                                                         |
| ---------------- | ------------------------------------------------------------ |
| 予約             | 利用者が特定の機材を予約期間中に利用する予定                 |
| 予約期間         | 利用開始予定日時を含み、返却予定日時を含まない期間           |
| 利用開始予定日時 | 予約者が機材の利用を開始する予定日時                         |
| 返却予定日時     | 予約者が機材を返却する予定日時                               |
| 予約中           | 貸出、予約取消、予約失効のいずれにも至っていない予約の状態   |
| 予約取消         | 予約者または管理者が、貸出前の予約を意図的に終了させること   |
| 取消済み         | 予約取消が完了した状態                                       |
| 予約失効         | 返却予定日時まで貸し出されず、予約として利用できなくなること |

予約可能なら承認を挟まず予約が成立するため、「確定予約」という別の用語は使わない。

## 貸出と返却

| 用語           | 意味                                                               |
| -------------- | ------------------------------------------------------------------ |
| 貸し出す       | 管理者が予約者本人へ機材を引き渡し、貸出日時を記録する操作         |
| 貸出中         | 機材を貸し出してから返却を確認するまでの状態                       |
| 貸出期間       | 実際の貸出日時から実際の返却日時までの期間                         |
| 返却する       | 借用者が機材を管理者へ戻すこと                                     |
| 返却を確認する | 管理者が機材を受け取り、状態を確認して実際の返却日時を記録する操作 |
| 返却済み       | 管理者による返却確認が完了した状態                                 |
| 貸出履歴       | 返却後も残す、借用者、貸出・返却日時、処理した管理者の記録         |
| 延滞           | 返却予定日時を過ぎても機材が貸出中であること                       |

## 使用しない言葉

| 使用しない言葉 | 代わりに使う言葉                   |
| -------------- | ---------------------------------- |
| 備品、設備     | 機材                               |
| 利用期間       | 予定なら予約期間、実績なら貸出期間 |
| 空いている     | 予約可能                           |
| キャンセル     | 予約取消                           |
| 期限切れ       | 予約失効                           |
| 返却受付       | 返却を確認する                     |
